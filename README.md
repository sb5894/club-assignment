# 우리 동아리 데모

학생 신청, 1→2→3지망 동일 확률 추첨, 교사 조정과 CSV 내보내기를 체험하는 사이트입니다.
입력 양식의 동아리 이름 12개만 반영했으며 실제 학생 자료는 포함하지 않습니다.

- 가상 학생 236명, 5·6학년을 사용합니다.
- 또래상담 기본 최소 6명·최대 8명, 나머지 최소 15명·최대 25명입니다.
- 최소 인원은 배정 후 검토 기준이며 강제 이동하지 않습니다.
- 학년과 성별은 분포만 보여주고 추첨 가중치로 사용하지 않습니다.
- 같은 입력과 추첨 번호는 같은 결과를 재현합니다. 학생과 동아리 입력 순서에 영향을 받지 않습니다.
- 상태는 React 메모리에만 있습니다. 새로고침하면 초기화되며 기기 간 공유되지 않습니다.
- 신청과 교사용 화면 전환은 체험 기능이며 사용자 인증이나 권한 분리가 아닙니다.
- CSV는 엑셀에서 열 수 있으며 JSON 기록에는 입력, 추첨 대상·당첨자, 교사 조정 사유를 담습니다.

실제 운영에는 중앙 데이터 저장, 교사 로그인, 학생별 신청 코드, 중복 수정 정책, 신청 마감과 백업이 필요합니다.
